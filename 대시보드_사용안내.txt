================================================================================
  충북교육청 결산 예상질의 스마트 네비게이터 & 대시보드 사용 안내 (v3.0)
================================================================================

사용자 요청 사항을 100% 반영하여 [자동 로딩 방지 & 초기화], [AI 기반 목차 자동 파싱],
[.env API 키 연동], [목차 연속 세로 스크롤 열람], [사이드바 탭(번호버튼 / 제목목록)] 기능이
완벽하게 적용되었습니다.

--------------------------------------------------------------------------------
1. 핵심 고도화 기능 안내
--------------------------------------------------------------------------------
① [페이지 열면 초기화 대기 (자동 로딩 방지)]:
   - 웹페이지에 접속할 때 폴더 내 PDF가 제멋대로 자동 로드되지 않습니다.
   - 깔끔한 초기 업로드 대기 화면(드롭존)에서 시작하여, 사용자가 직접 파일을 선택하거나
     드래그앤드롭했을 때만 파싱과 뷰어가 실행됩니다.

② [Gemini AI 기반 목차/문항 리스트 자동 추출 (정규식 탈피)]:
   - 부서마다 목차 서식이나 작성 스타일이 달라도 전체 구조(제목-목차-문항별 내용)가
     유사하면 Google Gemini AI가 앞쪽 목차(1~5p)를 분석하여 문항 번호, 카테고리,
     질의 제목, 문서 쪽수, 결산서/설명자료 연관 쪽수를 자동으로 정밀 구조화합니다.
   - AI 키가 없거나 네트워크 장애 시에도 기본 데이터셋으로 안전하게 자동 전환됩니다.

③ [.env 파일 API 키 연동 & 브라우저 이중 안전장치]:
   - 폴더 루트의 「.env」 파일에 GEMINI_API_KEY=AIzaSy... 형태로 키를 넣어두면
     웹앱 시작 시 자동으로 키를 읽어옵니다.
   - 로컬 file:// 보안 제약 환경에서도 상단 툴바의 [⚙️] 설정 버튼을 눌러
     브라우저 로컬 저장소에 키를 직접 등록/저장할 수도 있습니다.

④ [제목 옆 '목차 보기' 버튼 & 다단 연속 세로 스크롤 열람]:
   - 상단 툴바에 [목차 보기] 버튼이 복원되었습니다.
   - 목차가 1장이든 2장이든 3장이든, 번거롭게 한 장씩 넘길 필요 없이
     모든 목차 페이지를 세로로 한 번에 부드럽게 연속 스크롤(Continuous Scroll)하여
     한눈에 빠르게 열람할 수 있습니다.
   - 왼쪽 문항 번호나 제목을 누르면 즉시 해당 문항의 답변 페이지로 전환됩니다.

⑤ [사이드바 탭 지원: 번호 버튼 vs 제목 목록]:
   - 사이드바 상단에 모드 전환 탭이 탑재되었습니다.
   - [번호 버튼] 탭: 3열 바둑판 그리드와 0.3 버튼높이 간격으로 빠른 점프 지원.
   - [제목 목록] 탭: 카테고리별로 각 질의의 전체 제목 전문과 쪽수 태그를 세로로
     나열하여 마우스 휠로 정독하며 탐색할 수 있는 리스트 모드 제공.

⑥ [기존 최적화 100% 보존]:
   - 200% 대형 질의 제목 및 연관 페이지 뱃지
   - 정밀 마진 크롭 (좌 3.8%, 우 7.5%, 상하 2.7% 글자 잘림 완벽 방지)
   - 툴바 줌 컨트롤 자동 축소 반응형 및 모바일 지원
   - 배포 표준 파일인 「index.html」 규격 완비

--------------------------------------------------------------------------------
2. Gemini API 키 발급 및 설정 방법 (무료)
--------------------------------------------------------------------------------
1. Google AI Studio (https://aistudio.google.com/app/apikey) 접속 후 Google 계정 로그인
2. [Create API key] 버튼을 클릭하여 새 키 발급 및 복사
3. 작업 폴더 내 「.env」 파일을 메모장으로 열고:
   GEMINI_API_KEY=복사한키입력
   형태로 저장 (또는 대시보드 상단 툴바의 ⚙️ 버튼을 눌러 브라우저에 입력)

--------------------------------------------------------------------------------
3. 실행 및 웹 배포(Hosting) 안내
--------------------------------------------------------------------------------
- [로컬 실행]: 폴더 내의 「대시보드_실행하기.bat」을 더블 클릭하거나,
               「index.html」(또는 「스마트_결산질의_대시보드.html」)을 브라우저로 엽니다.
- [웹 배포]: 웹 표준 루트 진입 파일인 「index.html」로 준비되어 있으므로,
             GitHub Pages, Vercel, 사내 인트라넷 웹서버 등에 폴더 통째로 업로드하면
             즉시 대시보드가 구동됩니다.
