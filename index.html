무료 API 키 발급 방법:

  1. Google AI Studio (aistudio.google.com)에 로그인
  2. [Create API key] 버튼 클릭 후 키 복사
  3. 작업 폴더의 .env 파일의 GEMINI_API_KEY= 뒤에 붙여넣거나 위에 입력
