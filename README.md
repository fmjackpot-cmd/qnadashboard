# 예상질의 회의 대시보드

PDF 자료를 업로드해 관리자와 참여자가 함께 열람하는 브라우저 대시보드입니다. 관리자가 문항을 선택하면 참여자 화면에 우선 표시되며, 참여자는 각자 자유롭게 탐색할 수 있습니다.

## 로컬 실행

`.env.example`을 참고해 로컬 `.env`에 `ABLY_API_KEY`와 6자 이상의 `MEETING_ADMIN_KEY`를 설정한 뒤 실행합니다. 실제 키는 Git에 올리지 않습니다.

```powershell
.\run-local.bat
```

`http://localhost:8888`을 일반 창과 시크릿 창에서 각각 엽니다. 일반 창에서는 **관리자로 시작하기**로 PDF를 업로드하고, 시크릿 창에서는 **회의 참여하기**로 같은 회의 코드를 입력합니다. 종료는 터미널에서 `Ctrl+C`입니다.

## 검증

```powershell
.\run-tests.bat
```

자세한 검증 방법은 [tests/README.md](tests/README.md), 운영 배포 방법은 [Netlify_배포안내.md](Netlify_배포안내.md)를 참고하세요.

## 폴더 구성

| 경로 | 용도 |
| --- | --- |
| `index.html`, `app.js`, `live-session.js`, `style.css` | 화면·PDF 분석·회의 연결 |
| `netlify/` | 관리자 인증, Ably 전송, PDF 저장·조회 API |
| `scripts/` | 빌드와 로컬 실행 도구 |
| `tests/` | 자동 테스트와 검증에 필요한 PDF 2개 |
| `netlify-deploy/`, `netlify-deploy.zip` | 생성되는 배포 패키지, Git 제외 |
| `node_modules/` | 로컬 실행에 필요한 패키지, Git 제외 |
| `local-archive/` | 테스트에 사용하지 않는 PDF 원본의 로컬 보관, Git 제외 |

기본 PDF는 자동으로 열리지 않습니다. 관리자 업로드 한도는 50MB이며, 참여자는 회의 자료와 자료구분을 자동으로 받습니다. GitHub 푸시는 요청할 때만 진행합니다.

## 수감자료 프로토타입

초기화면에서 자료구분을 **행정사무감사 수감자료**로 선택한 다음 **관리자로 시작하기**를 누릅니다. 회의 설정에서도 업로드 전에 구분을 변경할 수 있습니다. 참여자는 자료구분이나 파일을 따로 선택하지 않습니다.

4.5MB를 넘는 파일은 3MB 단위로 자동 전송합니다. 서버에서 전체 SHA-256을 검증하고 관리자가 같은 자료를 다운로드·분석한 뒤 회의 자료를 전환합니다. 참여자도 조각을 합친 뒤 SHA-256을 검사합니다. PDF 파일 자체를 분할하거나 압축하지 않습니다.

수감자료는 문서 전체에서 목차를 찾아 소관부서·요구자료 번호·제목·인쇄 쪽번호를 읽습니다. 중간에 나오는 개별자료 목차, 열 제목이 생략된 연속 목차, 복수 소관부서를 처리합니다. 외부 AI 호출은 사용하지 않습니다. 문서 분석 진행 쪽수를 표시하며, 큰 자료는 각 기기에서 처음 분석하는 데 시간이 걸립니다.

현재는 텍스트가 포함된 동일한 표 양식을 대상으로 하는 로컬 프로토타입입니다. Netlify 실환경의 저장·전송 시간과 실제 Ably 연결은 배포 후 별도로 확인해야 합니다. 업로드 중 실패한 임시 조각의 자동 정리는 아직 구현하지 않았습니다. 배포 패키지 zip은 정적 화면이며 서버 함수 변경은 기존 Git/Netlify 빌드 경로로 함께 배포해야 합니다.
