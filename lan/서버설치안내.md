# Windows 서버 사용 안내

## 처음 실행

1. 설치 ZIP 전체를 원하는 쓰기 가능한 폴더에 압축 해제합니다. 실행 파일만 따로 이동하지 마세요.
2. **DashboardServer.exe**를 더블클릭하면 서버가 백그라운드로 시작되고 **서버 관리** 화면이 브라우저에 자동으로 열립니다.
3. **주소 복사**로 나온 주소를 같은 네트워크의 참가자에게 전달합니다. 회의 개설·진행 담당자에게는 **관리자 인증키 복사**로 복사한 키도 전달합니다. 일반 참가자는 키가 필요 없습니다.
4. 다른 PC에서 연결되지 않으면 **다른 PC 접속 허용**을 누르고 Windows 관리자 권한 확인을 허용합니다. 도메인·개인 네트워크의 같은 서브넷에서만 접속을 허용합니다. 기관 정책·게스트 와이파이·기기 격리로 차단된 경우 전산 담당자의 허용이 필요합니다.

최상위 관리자 비밀번호는 없습니다. 서버 PC에서 127.0.0.1 또는 localhost로 접속할 때만 관리 기능이 허용됩니다. 다른 PC에는 관리 메뉴가 표시되지 않으며, 관리 API도 차단됩니다. 서버 PC를 이용하는 사람은 관리 권한을 사용할 수 있습니다. 기존 SERVER_ADMIN_KEY 설정은 더 이상 사용하지 않습니다.

관리 화면의 **회의 화면 열기**로 회의 화면을 엽니다. 최초 화면에는 **회의 개설하기 / 회의 참여하기**가 있습니다. 새 회의는 이름·관리자 인증키·PDF로 개설합니다. 기존 회의의 진행 담당자는 **회의 참여하기 → 관리자로 참여**에서 인증하고 회의를 선택합니다. 일반 참가자는 **참여자로 참여**에서 인증키 없이 회의를 선택합니다.

## 관리와 종료

관리 화면에서 열린 회의와 종료된 회의 목록을 확인하고 **강제종료**할 수 있습니다. 종료된 회의의 참가자는 목록으로 돌아가며 재입장·자료 다운로드·화면 전송이 차단됩니다. 다른 회의는 계속 사용할 수 있습니다. 종료는 자료 삭제가 아니며, 새 회의는 다른 이름으로 개설하세요.

**브라우저를 닫아도 서버는 계속 실행됩니다.** 실행 파일을 다시 누르면 기존 서버의 관리 화면을 다시 엽니다. 모든 회의를 종료하려면 관리 화면에서 **서버 종료**를 누릅니다. 다시 시작하려면 실행 파일을 더블클릭하세요. 서버 PC는 켜 두고 절전 모드를 해제하세요.

## 자료와 설정

server-data에는 PDF·첨부·회의 상태·메시지가 저장됩니다. 목록·종료 상태와 최신 회의 화면은 재시작 후 유지됩니다. 메시지는 12시간까지만 보관되며 새 입장 전 메시지는 팝업으로 표시하지 않습니다. 같은 회의에 머무는 중 일시적 연결 끊김 후에는 놓친 메시지를 받습니다. 오래된 미사용 자료는 다음 업로드 때 정리됩니다.

일반 관리자 인증키는 첫 실행에 자동 생성해 .env에 저장하며 기존 키는 유지합니다. 키는 서버 관리 화면의 새 관리자 인증키와 확인란에 입력하고 **인증키 변경**을 누르면 즉시 변경·저장됩니다. 기존 관리자는 새 키로 다시 연결해야 하며 참가자 열람과 자료는 유지됩니다. 키는 6~128자의 영문·숫자·특수문자를 사용하고 공백·따옴표·역슬래시는 제외합니다. 백업·PC 이전은 서버를 종료한 상태에서 .env와 server-data를 함께 복사합니다. 이 파일과 자료 폴더를 배포하지 마세요.

기본 포트는 8888입니다. 변경하려면 서버 종료 후 .env에 DASHBOARD_PORT=9000처럼 설정하고 다시 실행합니다. 접속 허용 버튼도 변경한 포트에 맞춰 동작합니다. 서버 IP가 바뀌면 참가자 주소도 바뀌므로 고정 IP 또는 DHCP 예약이 편리합니다.

AI 분석은 선택 기능이며 인터넷과 별도의 Gemini 키가 필요합니다. 인터넷 외부 공개 구성, 자동 시작·Windows 서비스 등록은 포함하지 않습니다. 기존 start-server.bat과 allow-server-firewall.bat은 수동 실행이 필요한 경우를 위해 남겨 두었습니다.

## 패키지 생성

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-server-package.ps1

기본 출력은 dashboard-server-windows.zip입니다. 실행 파일·Node 런타임·PDF 라이브러리가 포함되며 .env·server-data·소스 저장소는 포함되지 않습니다.
